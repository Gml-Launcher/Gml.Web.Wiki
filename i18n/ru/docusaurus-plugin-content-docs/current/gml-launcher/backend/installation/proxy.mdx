# Настройка Proxy

Для настройки прокси для Gml Backend необходимо добавить следующие переменные окружения. Это полезно, если ваш сервер находится за прокси-сервером и ему требуется доступ к внешним ресурсам (например, к Маркету).

### Настройка в .env

Добавьте следующие переменные в ваш `.env` файл:

```yaml
# Proxy
HTTP_PROXY_ADDRESS=http://127.0.0.1:10801
HTTP_PROXY_USERNAME=
HTTP_PROXY_PASSWORD=
```

### Настройка в docker-compose.yml

Вы также можете указать эти переменные непосредственно в вашем файле `docker-compose.yml` для сервиса `gml-web-api`:

```yaml
  gml-web-api:
    image: ghcr.io/gml-launcher/gml.web.api:master
    # ... другие настройки
    environment:
      # ... другие переменные окружения
      - HTTP_PROXY_ADDRESS=http://127.0.0.1:10801
      - HTTP_PROXY_USERNAME=
      - HTTP_PROXY_PASSWORD=
```
