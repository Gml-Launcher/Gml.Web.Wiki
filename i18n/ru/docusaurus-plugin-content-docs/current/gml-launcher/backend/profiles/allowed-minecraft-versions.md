# Поддерживаемые версии Minecraft

GML поддерживает профили Vanilla, Fabric, Quilt, Forge, NeoForge и LiteLoader. Доступные версии загружаются из каталогов игры и загрузчиков.

## Диапазоны версий

| Загрузчик | Начальная версия в стандартной поставке | Верхняя граница |
|-----------|----------------------------------------|-----------------|
| Vanilla | 1.1 | Релизы из каталога Mojang, доступные установленной версии GML |
| Fabric | 1.14 | Версии с доступным Fabric Loader для выбранной версии игры |
| Quilt | 1.14 | Версии с доступным Quilt Loader для выбранной версии игры |
| Forge | 1.7.10 | Версии с доступной сборкой Forge для выбранной версии игры |
| NeoForge | 1.20.2 | Версии с доступной сборкой NeoForge для выбранной версии игры |
| LiteLoader | 1.5.2 | 1.12.2 |

Это ориентиры для выбора профиля, а не обещание наличия загрузчика для каждой промежуточной версии. В списке Vanilla GML показывает только версии типа `release`, без snapshots. Для модифицированных профилей версия Minecraft и версия загрузчика выбираются отдельно.

## Актуальность каталогов

Актуальные источники:

- [Каталог версий Mojang](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json).
- [Версии Minecraft для Fabric](https://meta.fabricmc.net/v2/versions/game).
- [Версии Minecraft для Quilt](https://meta.quiltmc.org/v3/versions/game).
- [Сборки Forge](https://files.minecraftforge.net/net/minecraftforge/forge/).
- [Сборки NeoForge](https://maven.neoforged.net/releases/net/neoforged/neoforge/).
- [Загрузки LiteLoader](https://www.liteloader.com/download) — последняя версия игры 1.12.2, сборки для неё помечены как snapshot.
