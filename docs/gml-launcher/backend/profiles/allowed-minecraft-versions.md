# Supported Minecraft Versions

GML supports Vanilla, Fabric, Quilt, Forge, NeoForge and LiteLoader profiles. Available versions come from game and loader catalogs.

## Version ranges

| Loader | Starting version in the standard distribution | Upper limit |
|--------|-----------------------------------------------|-------------|
| Vanilla | 1.1 | Mojang releases available to your installed GML version |
| Fabric | 1.14 | Versions with a Fabric Loader build for the selected Minecraft version |
| Quilt | 1.14 | Versions with a Quilt Loader build for the selected Minecraft version |
| Forge | 1.7.10 | Versions with a Forge build for the selected Minecraft version |
| NeoForge | 1.20.2 | Versions with a NeoForge build for the selected Minecraft version |
| LiteLoader | 1.5.2 | 1.12.2 |

These ranges guide profile selection; they do not guarantee a loader build for every intermediate version. GML lists only `release` versions for Vanilla, excluding snapshots. Modded profiles select the Minecraft version and loader version separately.

## Catalog reference

Current sources:

- [Mojang version catalog](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json).
- [Minecraft versions for Fabric](https://meta.fabricmc.net/v2/versions/game).
- [Minecraft versions for Quilt](https://meta.quiltmc.org/v3/versions/game).
- [Forge builds](https://files.minecraftforge.net/net/minecraftforge/forge/).
- [NeoForge builds](https://maven.neoforged.net/releases/net/neoforged/neoforge/).
- [LiteLoader downloads](https://www.liteloader.com/download): the latest Minecraft version is 1.12.2, with its builds marked as snapshots.
